# Architektur Grundprinzipien

- **MVC-Design:** Klassische Aufteilung in Model, View und Controller.
- **Generische Datenstruktur:** Datenstruktur soll so generisch und flexibel wie möglich sein.
- **XML-Content:** Konkreter Content wird aus beiliegenden XML-Dateien generiert.
- **Erweiterbares Model:** Das Model selbst soll stets erweiterbar sein.
- **Controller-Logik:** Der Controller beinhaltet die gesamte Logik.
- **Konfigurierbare Parameter:** Werte und Parameter sollen ebenfalls per XML-Dateien konfigurierbar sein.
- **Schlanke View-Schnittstelle:** Die Schnittstelle zur View ist so schlank wie möglich zu halten.
